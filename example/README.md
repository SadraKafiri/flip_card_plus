# flip_card_plus — Example App

An interactive showcase for the [`flip_card_plus`](https://pub.dev/packages/flip_card_plus) Flutter plugin.

## Showcases Included

| # | Tab | Description |
|---|-----|-------------|
| 1 | 💳 Payment Card | Credit card with realistic gradient, contactless icon, and signature strip |
| 2 | 🧩 Memory Match | 12-card matching game with emoji pairs |
| 3 | 🛍️ Product Card | E-commerce card with color/size selectors on the back |
| 4 | 📝 Flashcards | Quiz cards with score tracking |
| 5 | 👤 Business Card | Hover/touch-triggered profile badge |

## Running

```bash
flutter run
```

## Parent Package

See the main [flip_card_plus](https://pub.dev/packages/flip_card_plus) package for full API documentation.
